# Wythoff-public
## Jeu de Wythoff - Un etudiant en but Informatique 

Bonjour, Je suis un étudiant en BUT informatique qui souhaite vous donner la possibilité de vous aider si vous créer un jeu de Wythoff en Java. Ce projet n'est PAS une triche et doit être utilisé comme une simple aide, que ce soit pour les noms de variables, les fonctions ou la compréhension globale Rapellez vous : Chaque code étant personnel, vous devez pouvoir expliquer pourquoi vous avez codé tel ou tel fonction, donc si vous copiez mon code, au moins faites le bien et apprennez la façon dont ce jeu fonctionne. Egalement, les profs ont Github, il est possible qu'ils viennent vérifier le plagiat sur des projets OpenSource comme ici. Bref, prenez vos précautions, en espérant néanmoins vous aider ! 
  
/Il est possible que mon .class soit buggué, ou que l'environnement de travail Start et SImpleInput soit cassé. Dans ce cas, prenez simplement le fichier Wythoff.java, et compilez le sur votre machine directement/

~Un étudiant en but info
